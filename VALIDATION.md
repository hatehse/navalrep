# Проверка реализации

В текущей облачной среде Debian / Python 3.12 выполнены:

- `python -m pip install -e .` — успешно, с CPU-сборкой PyTorch для этой машины.
- `python -m pip check` — конфликтов зависимостей нет.
- `python scripts/run_ci.py` — **42 теста, все прошли, пропусков нет**.
- `python -m compileall -q main_pipeline.py src tests` — успешно.
- Консольная точка входа `navalrep --help` — успешно.
- `doctor` обнаруживает FFmpeg, libass, собранный h264_nvenc и Python-зависимости; возвращает ошибку готовности из-за отсутствующих модели и NVIDIA/CUDA-драйвера.

Проверены реальные синтетические монтажные склейки, извлечение PCM, пики громкости, фильтры FFmpeg, видимые жёлтые субтитры, итоговые длительности 35/55 секунд, ошибки и очистка. Тест рендера **явно подменяет** NVENC на libx264 только внутри тестового адаптера, поэтому GPU-кодирование им не проверяется.

## Сквозная проверка и полный размер кадра

`tests/test_end_to_end.py` проводит синтетический эпизод через реальные поиск сцен, извлечение WAV, анализ громкости, отбор, рендер, создание SRT/описания/JSON-отчётов и очистку. Получен клип длительностью 48 секунд. Проверены конец на склейке, попадание аудиопика в отбор, субтитры в кадре, сохранность исходника и чужого файла в рабочем каталоге.

В этом тесте **транскрипция задана заранее**, а NVENC заменён явным CPU-адаптером. Это проверка взаимодействия модулей, а не распознавания речи.

Дополнительный ручной CPU-прогон сформировал MP4 **1080×1920, 30 FPS, 43.266667 секунды** с аудио, синхронными испанскими субтитрами и описанием. Временные файлы удалены. При визуальном просмотре обнаружено и исправлено размещение субтитров: override `Alignment=5` в libass ставил текст сверху слева; корректный центр задаётся SSA-значением `10`. Регрессионный тест теперь проверяет реальные координаты текста на кадре, включая холст 1080×1920.

Отдельный тест запускает **настоящий дочерний процесс Whisper** с пустым локальным каталогом модели в офлайн-режиме. Он проверяет передачу ошибки инициализации, завершение процесса, удаление временного каталога и сохранность WAV; успешное распознавание им не проверяется.

Полноценные Faster-Whisper large-v3 / CUDA float16, потребление VRAM на RTX 4060 и NVENC на реальном эпизоде **не проверены**: в облачной машине нет NVIDIA GPU, модель не загружалась. Для приёмки на целевом ПК выполните подготовку модели, `doctor` и `run` по README.
