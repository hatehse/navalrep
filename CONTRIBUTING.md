# Работа над Navalrep

Начните с [README](README.md): там описаны установка, устройство пайплайна и настройки. Результаты исходной проверки и её ограничения находятся в [VALIDATION.md](VALIDATION.md).

## Окружение для разработки

Нужны Python 3.10–3.13, FFmpeg с libass и libx264, FFprobe и шрифт DejaVu Sans. На Ubuntu системные зависимости устанавливаются так:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg fonts-dejavu-core
```

Для тестов GPU и модель Whisper не требуются. На Linux/Windows в отдельном виртуальном окружении установите CPU-сборку PyTorch, затем проект:

```bash
python -m venv .venv
# Linux:
source .venv/bin/activate
# Windows PowerShell вместо source:
# .\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install "torch>=2.5,<3" --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e .
python -m pip check
python -m unittest discover -s tests -v
python -m compileall -q main_pipeline.py src tests
```

Для фактической генерации клипов используйте CUDA-сборку PyTorch и инструкцию из README; не заменяйте существующую рабочую CUDA-установку CPU-сборкой ради тестов.

## Изменения и проверки

Создавайте отдельную ветку под задачу и делайте коммиты с конкретным назначением, например `fix: сохранять синхронизацию SRT после ускорения`. В pull request объясните проблему, новое поведение и выполненные проверки.

При изменении поведения добавляйте тест, который воспроизводит проблему. Проверьте, что нужные интеграционные тесты действительно выполнились: `skipped` из-за отсутствующего FFmpeg или зависимости не подтверждает работоспособность этого этапа.

Сохраняйте последовательность тяжёлых этапов и завершение процесса Whisper до рендера. Диапазон 35–55 секунд относится к готовому видео после изменения скорости. CPU-подмена NVENC допустима только в явно обозначенном тестовом адаптере; она не проверяет CUDA, расход VRAM или аппаратный кодировщик.

Если изменение затрагивает CUDA или NVENC, отдельно укажите, проверялось ли оно на NVIDIA GPU, на какой модели и с какой версией драйвера. При отсутствии такой проверки напишите это прямо.

## Что хранить в Git

Исходные видео, скачанные модели, `.venv`, логи и содержимое `output/`/`temp/` остаются вне коммитов. Личные пути и настройки держите в локальной копии конфигурации. Перед отправкой проверьте `git status` и состав коммита.

Для сообщения об ошибке используйте шаблон issue: укажите шаги воспроизведения, версии и короткий фрагмент лога без токенов и личных данных. Прикладывать исходное видео не обязательно; синтетический пример предпочтителен, если он воспроизводит проблему.
